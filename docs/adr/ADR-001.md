# ADR-001 - Choix de la distribution Kubernetes legere K3s pour l'hebergement de la plateforme OmniPay Zero-Trust

| Champ | Valeur |
| :--- | :--- |
| **Porteur** | P3 - Plateforme, IaC, reseau et conformite |
| **Statut** | Accepte |
| **Date** | Semaine 1 |

## Contexte

La plateforme OmniPay Zero-Trust doit executer toute la chaine DevSecOps (microservices Java,
PostgreSQL, Jenkins, Harbor, ArgoCD, Prometheus, Grafana) sur une machine etudiante ou une VM
aux ressources limitees (RAM/CPU). L'orchestrateur doit etre conforme aux APIs Kubernetes
officielles, rapide a provisionner et entierement reproductible par code
(`terraform destroy` / `apply`, test de reproductibilite de la Semaine 4).

## Decision

Adopter **Rancher K3s** comme orchestrateur unique, installe et durci par Ansible, avec les
namespaces provisionnes par Terraform.

## Alternatives comparees

| Option | Avantages | Inconvenients | Verdict |
| :--- | :--- | :--- | :--- |
| **K3s** | Leger (< 512 Mo pour le control plane), certifie CNCF, containerd + Flannel inclus, install en < 60 s | Traefik embarque par defaut | **Retenu** |
| Kubernetes vanilla (kubeadm) | Reference upstream | Lourd, installation longue et complexe, plusieurs Go de RAM | Rejete |
| MicroK8s | Simple, addons | Dependance a snap, moins adapte a l'automatisation Ansible multi-OS | Rejete |
| k0s | Leger, binaire unique | Ecosysteme et documentation moins repandus | Rejete |
| Minikube | Facile pour le dev local | Mono-noeud par conception, pas un modele de deploiement reproductible | Rejete |

## Consequences

**Positives**
- Empreinte < 512 Mo de RAM pour le control plane : toute la stack tient sur une machine etudiante.
- Conformite CNCF : les manifestes et APIs sont portables vers un Kubernetes standard.
- containerd natif, demarrage rapide : ideal pour le test `destroy` / `apply` de la Semaine 4.
- Support des Pod Security Standards (labels `restricted` sur les namespaces).

**Negatives et mitigations**
- Traefik est embarque par defaut. *Mitigation :* desactive a l'installation
  (`--disable traefik`) car Ingress NGINX sera deploye en Semaine 2.
- Kubeconfig K3s en mode 644 pour faciliter l'usage local. *Mitigation :* copie utilisateur en
  0600 par le playbook ; a durcir en 600 hors contexte de laboratoire.
